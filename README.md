# Ananta Industries Business System v3.0 — Nova UI

## UI redesign
- Completely new animated Nova Blue interface based on the Ananta logo palette.
- Premium login hero, compact correctly-fitted logo, animated aurora background and refined access card.
- New sidebar, top bar, dashboard KPI tiles, quick-action hub, table/form/modal styling and responsive mobile behavior.
- Rich micro-interactions, hover motion, progress accents and reduced-motion accessibility fallback.
- Logo is intentionally used only in strong brand positions instead of being repeated everywhere.

## GST invoice branding
- Main Ananta logo is kept at the top of the tax invoice.
- Signature area has NO logo; it is a clean signing space with company name, line and authorized signatory.
- Footer uses a clean wordmark instead of repeating the logo.
- Existing GST invoice fields, tax split, HSN, place of supply, payment status, bank details, PDF/print flow and security behavior are retained.

npm install
npm run verify
