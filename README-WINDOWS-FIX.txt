ANANTA INDUSTRIES MANAGEMENT SYSTEM v1.0.1 - WINDOWS STARTUP FIX

FIXED
- Removed Electron self-spawn completely.
- Fixes: spawn C:\Program Files\Ananta Industries Management System\...exe ENOENT
- Express now runs inside Electron's main process.
- Uses a free localhost port automatically, avoiding port 4173 conflicts.
- Writable live database is stored in Windows AppData, not Program Files.
- Invoice PDF remains generated in a dedicated hidden invoice window.

IMPORTANT: BEFORE INSTALLING THE NEW BUILD
1. Uninstall the old "Ananta Industries Management System" from Windows Settings > Apps.
2. Delete the old project dist folder if it exists.
3. Extract this ZIP to a NEW folder.
4. Open PowerShell in that folder.

BUILD COMMANDS
npm install
npm run verify
npm run build:win

Or right-click BUILD-WINDOWS-EXE.ps1 > Run with PowerShell.

INSTALL
After build completes, open dist and run:
Ananta-Industries-Management-System-1.0.1-x64.exe
(or the similarly named x64 .exe generated by electron-builder)

FIRST START
The app creates its writable store.json under the user's AppData/Roaming Electron userData folder automatically.
No npm start command is required after the Windows app is installed.
